PipPal — Screens
Step 2 of 4 · iPhone 16 Pro / 17 · 402 × 874 pt
Every screen is drawn at true point size inside a real device frame, so what you see is what a 6.3-inch iPhone shows. Screen padding is 16pt, cards are 12px radius on 1px warm borders, and all numbers are tabular. The tab bar keeps the five-slot rhythm users already know from Instagram, X and YouTube — four tabs (Dashboard, Journal, Calendar, Analytics) with the create action in the centre, but it floats as a translucent pill {{ navHeight }} tall, inset {{ navInset }} from the edges and lifted {{ navLift }} clear of the bottom, so the ground reads all the way around it. It is glass rather than a panel: a {{ navBlur }} backdrop blur at {{ navSaturate }} saturation over a {{ navGlass }} gradient, a light hairline and an inset top highlight, with content passing beneath it, which is why lists clip under the pill instead of stopping above it. Every tab carries an icon and a label, since labels are what make a five-slot bar legible on first use. Icons are drawn on one 24pt grid at a 1.75 stroke with rounded joins, and the active tab switches to the filled version of its own glyph, as iOS does, inside a faint crimson lens. Active ink is {{ navActiveInk }}, stepped down from the base crimson because base crimson on this composite measures 3.71:1; idle ink is solid {{ navIdleInk }} at full opacity, never alpha-dimmed, so 10pt labels clear 4.5:1 on the glass. Screens pushed on top of a tab, like Trade Detail and Week in Review, show no capsule at all, and any screen with its own bottom action reserves clearance so the button never sits under the glass. Pan and zoom freely. The iPad Air 13-inch layout follows below the phones.

Sign-up & first run
In flow order. Sign-up is passwordless first: Apple, Google, or an email plus a 6-digit code, so nobody meets a password field before they know the email works. A password is set only after the code is verified, which is what lets returning users sign in with email and password and use a reset link. The wrong-credentials banner never singles out a field, so it doesn’t reveal which one was wrong. Onboarding artwork is built from real app components with sample data, not illustrations.
