# 03 · Screens

Main visual reference: `claude/PipPal Screens.dc.html` (open it in a browser; each screen carries its code label).
Phone frame: **iPhone 16 Pro / 17 — 402×874pt**. iPad: **iPad Air 13" landscape — 1366×1024pt**.
Screen codes follow the spec; S15 is reassigned to Weekly Review. `[Dn]` refers to design decisions in `08-open-questions.md`. Where a decision changes a drawn screen, **the decision wins over the drawing**.

## Log Trade (opened from the ＋ centre tab)
| Variant | Status | Content |
|---|---|---|
| **B · Quick log** | **Default** | Bottom sheet sized to content. Segmented header "Quick log / Full form". "Three fields now. Add prices, notes and tags whenever you like." INSTRUMENT: the five most-used pairs as chips (ordered by frequency) + "Other…". DIRECTION: BUY/SELL. RESULT: one field + unit switch **$ / pips / R**, helper "Enter whichever you know. PipPal back-fills the rest once you add prices." **New [D7]:** a compact "Followed plan?" **Yes / No** row under Result, unset by default (No reveals the optional reason chips). Note: "Quick-logged trades appear in your journal with an Incomplete tag until you add prices. They still count toward win rate." **Save trade** + **+ Details**. No partial exits |
| A · Full form step 1 | Secondary path | "Log a Trade" / "Step 1: Trade details", "1 / 2". Instrument, BUY/SELL, Entry, Exit, Lot size, Stop loss, open and close date-time. **New:** optional **Take profit** field [D9]; "+ Add partial exit" link under Exit (price + % rows that must total 100%) [D8]. Live readout "CALCULATED LIVE · 0.0001 pip size, USD account": +48.0 pips · +$96.00 · RR 1:2.0. If the quote currency isn't the account currency, $ isn't calculated and the user enters the $ result [D10]. Crypto/stocks show no pips [D11]. **Next: notes & tags** |
| C · Step 2 | Secondary path | "Step 2: Notes & details", "2 / 2", summary chip. **New [D7]:** "Followed my plan?" Yes/No above Notes; No reveals reason chips (Chased entry · Moved stop · Oversized · Exited early · No setup · Revenge trade). NOTES (500-char counter, placeholder "What happened? "← Back" / **Save Trade** |

Sheet behaviour: grab handle, scrim, drag-to-dismiss. If any field has a value, ask "Discard this trade?". On save: toast "Trade saved to your journal." with **View**, plus a success haptic.

## Tablet / iPad layouts [D25]
- **< 600 wide:** phone layout.
- **600–1023** (iPad portrait, small tablets): icon-only **72pt** sidebar, single pane.
- **≥ 1024:** the drawn layout below.

### iPad (1366×1024 landscape)
A permanent **248pt left sidebar**: logo + "PipPal", full-width **Log Trade** primary button, the four destinations (22pt icons; the active item is filled `#A03B44` on a crimson-10% row; Journal shows a count badge "42"), SAVED FILTERS (Winning trades, Breakout setups, Incomplete entries [3]), and a user row at the bottom ("Ade K." / "Real account · USD"). Journal is **two-pane**: a 420pt list (Sort: Newest, search, chips All/BUY/SELL/Profit/Loss, "42 trades · Net … · +186 pips") with Trade Detail filling the rest. Padding 32.
