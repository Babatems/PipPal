## `claude/`: design handoff bundle
| File | Role | Use it for |
|---|---|---|
| `README.md` | **Developer handoff.** Tokens, nav, every screen, behaviour, state, spec overrides | First stop for any design question |
| `PipPal Screens.dc.html` | **Main visual reference.** Every phone screen, Log Trade A/B/C, edge states, Settings, app icon, iPad. Its logic block holds the July sample data and nav ink rationale | Pixel details, copy, SVG paths |
| `PipPal Foundations.dc.html` | Token and component sheet: colours, type, spacing, buttons in all states, inputs, tags, cards, nav, feedback, emotion pickers (A emoji vs B drawn), dark-mode samples | Component states |
| `PipPal Logo.dc.html` | Logo exploration, turns 1–6 (newest first). The chosen mark is **5a** (turn 5) | Logo construction notes |
| `Motion Steps.dc.html` + `motion-steps-piece.jsx` | Splash animation stage and the 3-scene piece (stem → bowl → candle) | Splash timings and curves |
| `animations-v3.jsx` | Animation runtime used by the motion viewer (`CompositionStage`, `Easing`, `animate`) | Viewer only; don't port |
| `PipPal Design Brief.dc.html` | Pre-design research brief: what the spec settles, research insights, the token conflict, build order | The "why" behind decisions |
| `ios-frame.jsx`, `support.js` | Viewer support (device frame, `.dc.html` runtime) | Not app code |
| `reference/PipPal UI_X Design Specification.pdf` | Original 33-page spec | Background; designs override it |
| `reference/spec.txt` | Text extraction of the PDF | Grep-able spec |

Viewing: open the `.dc.html` files in a browser from inside `claude/`; they load `./support.js` and Inter from Google Fonts.
